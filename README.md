A tiny, deterministic program for the make.fun competition
"Worst AI Advice". It writes exactly one line — the worst advice an
AI could give, in a confident assistant voice — to
`/output/entry.txt`:

> To save time in the morning, iron your clothes while wearing
> them: the heat smooths the fabric and your day starts with real
> momentum.

The program checks this competition's 1–140 character gate itself
before writing. No network, no randomness: every run produces the
same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
